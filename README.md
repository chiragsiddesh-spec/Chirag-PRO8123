## 🌟 Key Highlights & Features

- **Left-Mounted Vertical Navigation**:
  - Fixed glassmorphism sidebar with neon orange energy boundary.
  - Numbered HUD navigation items (`01 ABOUT`, `02 PROJECTS`, `03 SKILLS`, `04 QUESTS`, `05 CONTACT`).
  - ScrollSpy active link tracking as sections come into view.
  - Responsive mobile slide-out drawer with frosted backdrop overlay.
- **Pixel Art Hero Section**:
  - Custom pixel art city skyline backdrop with CRT scanlines overlay.
  - Welcoming title & tagline tailored for recruiters and collaborators.
  - Retro RPG Stats HUD bar (HP, EXP, MP).
  - Night / Day mode toggle that auto-detects browser `@media (prefers-color-scheme)` with persistent manual override.
- **Persona & Avatar Switcher**:
  - Dual-mode portrait dossier allowing instant switching between verified photo and custom anime digital avatar.
- **Manga Panels Project Archive**:
  - Filterable project case files with hover zoom, speedline accents, and technical specifications.
  - **College Lost & Found**: Campus recovery platform with categorical search and claiming lifecycle.
  - **Algo-Visualizer // Pathfinding**: Real-time graph traversal engine (A*, Dijkstra) on interactive mazes.
  - **Smart Waste Monitor // IoT**: Hardware telemetry system with ultrasonic sensors and live web console.
  - Full-detail project dossier modal with architecture specifications and GitHub links.
- **Power System Ability Matrix**:
  - Categorized skill breakdown (Core Languages, Web Development, Systems & Tools).
  - Authentic descriptive mastery tiers (*Building*, *Practicing*, *Learning*, *Improving* — no arbitrary percentage bars).
- **Current Quest Log**:
  - RPG-inspired growth milestones tracking active computer science objectives and internship preparation.
- **One Piece Straw Hat Interactive Cursor**:
  - Custom SVG Straw Hat cursor with follower aura.
  - Dynamic movement particle trail (Golden straw embers, Conqueror's Haki crimson sparks, and steam vapor).
  - Conqueror's Haki shockwave radial burst on mouse clicks.
  - Toggleable via the floating HUD widget.
- **Atmospheric Sakura Flowers Engine**:
  - 48 delicate Japanese cherry blossom petals and 5-petal complete flowers floating across the background.
  - 3D tumbling oscillation, sinusoidal wind sway, and interactive mouse-draft deflection.
- **Web Audio API Sound Synthesizer**:
  - Zero external audio files — synthesized sine and sawtooth frequencies for clicks, toggles, and modal transitions.

   ```bash

   cd Chirag-PRO8123
   ```
2. Open `index.html` in your favorite web browser (or use Live Server / any static HTTP server).
